# Low-cost autonomous backlog

このファイルは、AI Game Director の低コスト定期実行で扱ってよい改善候補を限定するためのキューです。

## 運用ルール

- GitHub Actions は毎時起動するが、OpenAI API を呼ぶのは日本時間 03:00 / 09:00 / 15:00 / 21:00 頃の最大4回/日だけにする。
- さらに、未完了項目があり、AI Game Director の未処理PRがなく、mainのCIが正常な場合だけ自動改善を実行する。
- 定期実行では `gpt-5.6-luna` + low reasoning を使い、1回1改善に限定する。
- 定期実行で自動公開できるのは、純粋ロジック・テスト・このキュー・current-plan などの限定された安全範囲だけ。
- Visual / Art、React画面、CSS、画像、問題本文・年代別シチュエーション、Secret、課金、外部送信は定期実行で変更しない。
- Image API は定期実行から呼ばない。
- 各項目がすでに満たされている場合は、根拠を確認してチェック済みにし、無理にコードを変更しない。
- キューが空になったらAPIを使わず停止し、次の候補はChatGPT / 人間レビューで補充する。

- [ ] `sceneOrder` の短いモード / 10問上限 / 終幕固定 / 重複なし / 再プレイ順序差の回帰条件を再点検し、不足しているテストだけ補強する。
