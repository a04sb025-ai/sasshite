# ゲームビジョン

この文書は「察して。」が長期的に目指すゲーム体験の正本です。機能追加、問題追加、UX改善、自律改善を行うAIは、この文書と `AGENTS.md` を優先して判断してください。

## コア体験

「察して。」は、正解を暗記するクイズではありません。

プレイヤーが場面を見て、触る、動かす、選ぶ、待つ、何もしないなどの行動を取り、その結果として場の空気がどう変わるかを楽しむゲームです。

目標は、幼稚園児から大人まで、それぞれ自分に近い生活世界の「このときどうする？」を遊べることです。

## 年代別モード

将来的に次の7モードを持ちます。

1. 幼稚園
2. 小学生低学年
3. 小学生高学年
4. 中学生
5. 高校生
6. 大学生
7. 社会人

各モードは30〜50シチュエーション以上を目標とし、1プレイではその中から約10問を出題します。

同じ問題を暗記するだけで高得点にならないよう、1つのシチュエーションに複数の妥当な行動、条件差、反応差を持たせます。

## リプレイ性

1プレイの最後に100点満点を基本とするスコアを表示し、自己ベスト更新を目指したくなる設計にします。

ただし、単純な正解数だけでは評価しません。内部では、たとえば次のような複数軸を扱えます。

- 察知
- 気遣い
- 距離感
- 自己主張
- 迷い / タイミング

同じ総合点でも行動傾向が異なる結果を許容します。

## 操作の多様性

文章を読んで選択肢を押すだけのクイズへ寄せません。シチュエーションに応じて、次のような操作を組み合わせます。

- タップ
- ドラッグ
- 長押し
- タイミング操作
- 場所の選択
- 会話や行動の選択
- あえて何もしない

自由入力とAI判定は将来候補ですが、通常プレイの必須要件にはしません。AI判定を導入する場合も、固定ルールによる採点を基準として残し、再現性を失わないようにします。

## 子どもも遊べること

低年齢モードでは文章量を減らし、絵と操作から理解できることを優先します。

- 幼稚園〜小学校低学年は、ひらがな中心・短文・視覚中心を基本とする。
- 必要に応じて読み上げ対応を検討する。
- 低年齢では点数による否定的な人格評価をしない。
- 「あなたが悪い」ではなく、「こうするとこんな反応になった」と行動と結果を返す。
- 教材・道徳テストの雰囲気より、遊びとしての発見を優先する。
- 個人情報入力、知らない人とのチャット、子どもの自由入力保存をゲーム成立の前提にしない。

## 難易度の考え方

年齢が上がるほど、単純に文章を難しくするのではなく「どれも少し分かる」「状況次第」という曖昧さを増やします。

低年齢では、相手の表情・順番・共有・距離など視覚で理解しやすい空気を中心にします。

中高生以降では、友人関係、先輩後輩、グループ、恋愛、バイト、会議、取引先など、複数人の利害や暗黙の期待を含む状況を増やします。

## AI開発への原則

AIは「機能を増やすこと」自体を改善とみなしません。

変更は、ゲームとしての分かりやすさ、操作感、空気読み感、迷いの面白さ、リプレイ性、年代適合性、安全性のどれを改善するためか説明できる必要があります。

自律改善の詳細は `docs/autonomous-development.md`、評価基準は `docs/evaluation-rubric.md`、年代ごとの問題設計は `docs/age-modes.md` を参照してください。
