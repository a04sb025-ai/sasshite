# Game Vision

## 一文でいうと

「察して。」は、幼稚園児から大人まで、それぞれの年代で起こる微妙な空気を、説明ではなく情景と操作から察して遊ぶスマートフォン向けゲームです。

正解を教える教材ではなく、「このとき自分ならどうする？」を楽しみ、何度も挑戦してより高いスコアや別の結果を狙いたくなるゲームを目指します。

## 長期的なプレイ構造

プレイヤーは年代モードを選びます。

- 幼稚園
- 小学生低学年
- 小学生高学年
- 中学生
- 高校生
- 大学生
- 社会人

各年代は最終的に30〜50以上のシチュエーションを持ち、1プレイではその中から約10問を出題します。

同じシチュエーションでも複数のもっともらしい行動、操作、条件差を持たせ、単純に答えを暗記して終わらない構造を目指します。

## リプレイしたくなる理由

プレイヤーが「もう一度やろう」と思う理由を最低でも複数持たせます。

- 前回より高い点数を取りたい。
- 自己ベストを更新したい。
- まだ見ていないシチュエーションが出るかもしれない。
- 同じ場面でも別の行動を試したい。
- 年代を変えると違う種類の空気が出る。
- 自分の行動傾向や結果の違いを見たい。

スコアはリプレイ動機として重要ですが、子ども向けでは低得点で人格や能力を否定されたと感じる設計にしません。

## 「選択肢ゲーム」だけにしない

問題形式はシチュエーションに合わせて選びます。

- タップ
- ドラッグ
- 場所を選ぶ
- タイミングを待つ / 動く
- 会話や行動を選ぶ
- あえて何もしない
- 将来的なAI自由回答判定

文章の3択を繰り返すだけにはしません。プレイヤーが画面の中の世界へ働きかけ、その結果を見られることを重視します。

## 正解の考え方

このゲームは「マナーの唯一の正解」を教えるゲームではありません。

行動には、気遣い、察知、距離感、自己主張、やりすぎ、ためらい等の複数軸を持たせられます。

良い行動が複数ある場面を許容します。状況によっては何もしないことも合理的です。

プレイヤー本人ではなく、選んだ行動とその場への影響を評価します。

## 子どももプレイできることを前提にする

低年齢ほど次を重視します。

- 絵と動きだけでも状況を理解しやすい。
- 文章を短くする。
- 幼稚園〜低学年はひらがな中心を基本候補とする。
- 大きなタップ領域を使う。
- 強すぎる刺激や急な演出を避ける。
- 「間違い」「空気が読めない子」など人格評価をしない。
- 個人情報入力や知らない人との交流を必要としない。

AI自由回答判定を将来導入する場合も、低年齢モードでは自由入力を必須にせず、保存・外部利用・フィードバック文言について別途安全設計を行います。

## 年代が上がるほど複雑になる

難易度は反射神経ではなく「空気の複雑さ」で上げます。

幼稚園では、遊び、おもちゃ、順番、友達、家族など身近で視覚的な状況を中心にします。

年代が上がるにつれ、グループ関係、先輩後輩、部活、恋愛、アルバイト、会議、取引先など、複数の立場を同時に考える状況を増やします。

大人になるほど明確な唯一解が減っていく設計を目指します。

## AIと自律開発

このゲームは、ユーザーが毎回詳細な実装仕様を書かなくても継続的に育てられることを目標にします。

AIは、現在のゲーム、評価基準、ユーザーが過去にOK / NGした結果を参照し、改善候補を考え、小さな実験として実装・検証します。

ただし「面白さ」を自動テストだけで決めません。視覚、操作感、笑い、違和感、子どもが理解できるか等は人間のPreview確認を残します。

最初は1回1改善の人間承認付きループから始め、実績と回帰テストが蓄積した後にのみ複数サイクル・定期実行へ進みます。

## 守るもの

- スマホを主端末にする。
- 状況説明を増やしすぎない。
- 操作すると世界が変わる感覚を持たせる。
- Before / Afterや結果の変化が分かる。
- 絵と操作をゲームロジックから適切に分離する。
- 正解表示より、世界の反応を見せる。
- 子どもを含むプレイヤー本人を否定しない。
- 既存の正常な操作を、見た目変更のために壊さない。

## やらないこと

- 教科書のようなマナー教育ゲームにする。
- 長文説明を読まないとプレイできない設計にする。
- 全年代で同じシチュエーションを文言だけ変えて使い回す。
- 一度遊んだら答えを暗記して終わる構成にする。
- 低得点を人格評価として見せる。
- AIがmainへ無条件で自動マージする。
