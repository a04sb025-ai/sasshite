# 年代別モード設計

この文書は、年代別にどのような空気読みシチュエーションを扱うかの設計ガイドです。問題を大量生成する際は、年代に合わない場面や似た問題の量産を避けるために使用します。

## 共通ルール

各年代は30〜50シチュエーション以上を目標とします。1プレイは約10問です。

各問題は最低限、次の情報を持てる構造を目指します。

- 対象年代
- 場所 / 文脈
- 登場人物と関係
- 表面的な状況
- プレイヤーが察する対象
- 可能な行動
- 各行動による場面変化
- スコアへの影響
- 難易度
- 類似問題を避けるためのタグ

明確な唯一正解を毎回作る必要はありません。複数の妥当な行動と、それぞれ異なるトレードオフを持たせることを推奨します。

## 幼稚園

主な世界:

- 家族
- 園の教室
- 園庭
- おもちゃ
- 順番
- おやつ
- 友達との遊び

設計:

- 絵だけでも状況が分かることを最優先にする。
- 文章は最小限、ひらがな中心。
- タップ / ドラッグなど直接操作を多くする。
- 誰かを傷つけるような強い失敗表現を避ける。

## 小学生低学年

主な世界:

- 教室
- 休み時間
- 給食
- 登下校
- 公園
- 習い事
- 友達との貸し借り

設計:

- 短い文章 + 視覚操作。
- 順番、共有、困っている人、仲間に入る / 入れないなどを扱う。
- 大人の職場マナーを子ども用に言い換えただけの問題は作らない。

## 小学生高学年

主な世界:

- グループ活動
- 委員会
- クラブ
- 友達同士の距離
- メッセージのやり取り
- 発表や係

設計:

- 同じ行動でも相手との関係で意味が変わる問題を増やす。
- 露骨な正解 / 不正解より、少し迷う選択を増やす。

## 中学生

主な世界:

- 部活
- 先輩後輩
- 教室
- グループ
- 友人関係
- SNS / メッセージ
- 学校行事

設計:

- 複数人の関係性を含む状況を増やす。
- 「黙る」「間に入る」「距離を取る」など、何もしないことも正式な選択肢に含める。

## 高校生

主な世界:

- 友人関係
- 部活
- 恋愛に近い距離感
- バイト
- 進路
- 行事
- SNS

設計:

- 正解が一つに見えない問題を増やす。
- 相手への配慮と自分の意思のバランスを扱う。
- 恋愛要素は全年齢向けの軽い距離感・気まずさの範囲にとどめる。

## 大学生

主な世界:

- サークル
- ゼミ
- バイト
- 友人関係
- 飲み会を含む集まり
- 就活
- 共同作業

設計:

- 初対面、先輩後輩、友人、店員、教授など関係性の幅を増やす。
- 飲酒そのものをゲームの成功条件にしない。飲まない選択も不利にしない。

## 社会人

主な世界:

- 会議
- 上司 / 後輩
- 取引先
- オンライン会議
- エレベーター
- 休憩室
- 飲み会・会食
- 退勤時
- 共有スペース

設計:

- マナー暗記ではなく、相手・時間・人数・立場のバランスを読む問題にする。
- 「空気に従うこと」が常に高得点にならないようにする。
- 必要な自己主張や断る判断にも妥当な評価を与える。

## 問題プールの品質

AIが問題を追加する場合、次を満たさない問題は採用しません。

1. 対象年代で自然に起こりうる。
2. 既存問題の言い換えだけではない。
3. 何をすべきか一目で明白すぎない、または直接操作として面白い。
4. 行動後に場面の変化を見せられる。
5. 説教・道徳テストのような人格評価にならない。
6. 子ども向けでは年齢に合う語彙と安全性を守る。
7. 少なくとも2つ以上の意味のある行動候補を持てる。
